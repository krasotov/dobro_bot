# Standalone-режим (без admspgo)

## Что работает без `ADMSPGO_*`

- Регистрация и меню бота
- Веб-админка `/admin` (пользователи, рассылки, скриншоты, staff, канал новостей)
- Транспорт и служебные записки (данные в PostgreSQL бота)
- `INTERNAL_API_TOKEN` — машинный API для тех же сущностей, что и админка

## Что отключено, если не заданы `ADMSPGO_API_URL` и `ADMSPGO_INTERNAL_TOKEN`

- Отправка обращений жителей на внешний портал
- Справочник, темы подписок, опросы, мероприятия (контент с внешнего API)
- Синхронизация служебных записок во внешнюю систему
- Фоновый опрос чатов для соцмониторинга и пересылки сообщений ЖКХ на портал

Команды бота, которые обращаются к API, просто не находят данных — ошибок деплоя не будет.

## Nginx

В `deploy/nginx.conf` **нет** редиректа админки на сторонний сайт: `/admin` проксируется в приложение. На своём VPS замените `server_name` и пути SSL на ваш домен.

## Новый инстанс для другой организации

1. Новый бот и токен в MAX.
2. Свой домен и VPS, пустая БД.
3. Свои `ADMIN_*`, `SECRET_KEY`, `INTERNAL_API_TOKEN` (если нужен API).
4. Не передавайте prod `.env` и дампы БД без юридического оформления ПДн.
